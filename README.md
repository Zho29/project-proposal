# StockSim — Learn to Invest Without the Risk

## Project Title

**StockSim: A Risk-Free Stock Market Simulator for Beginner Investors**

---

## What and Why?

Millions of young adults want to start investing but are held back by one thing: **fear of losing real money**. The financial markets are complex, volatile, and intimidating for anyone without experience. Traditional investing education — textbooks, YouTube videos, and online articles — is passive. Nothing truly prepares you for the emotional and strategic decisions of real investing like *actually doing it*.

**StockSim** is a mobile web application that simulates the real stock market using live or near-live market data, but with virtual money. Users can build and manage a portfolio, buy and sell stocks, track gains and losses, and learn investing concepts — all without risking a single real dollar.

The need for this is clear: financial literacy is one of the most underdeveloped skills among young adults. A hands-on investing simulator directly fills this gap in a way that passive learning cannot.

---

## For Whom?
StockSim is built for **college students and young adults (ages 18–28)** who are curious about investing but have never opened a brokerage account. These are people who:

- Have heard about stocks, ETFs, and crypto but don't know where to start
- Are nervous about losing real money and want a safe environment to practice
- Want to understand how portfolios work before committing real savings

This is not software for imaginary users. These are our friends, classmates, and peers — many of whom have expressed interest in investing but feel overwhelmed by apps like Robinhood or Fidelity that assume prior knowledge. We have spoken with several students on campus who confirmed they would actively use a guided, judgment-free simulator.

---

## How?

From the end-user's perspective, StockSim works like this:

- **Onboarding**: A new user signs up and receives a virtual portfolio funded with **$10,000 in simulated cash** to start investing.
- **Market Feed**: Users browse real (or simulated) stock data — price, trend charts, and basic company info — across major stocks and ETFs.
- **Buy & Sell**: Users can place market orders for any stock using their virtual cash.
- **Portfolio Dashboard**: A clean dashboard shows the user's total portfolio value, individual stock holdings, daily gains/losses, and overall return since starting.
- **Learning Modules**: Short, contextual lessons are surfaced at relevant moments (e.g., "What is a P/E ratio?" when a user views a stock detail page).
- **Leaderboard**: An optional social leaderboard lets users compare portfolio performance with friends or classmates, adding a fun competitive layer.
- **Achievements**: Milestone badges reward users for learning behaviors (e.g., "First Trade", "Diversified Portfolio", "Beat the Market").

The app is designed to be mobile-first, intuitive, and beginner-friendly — jargon is always explained, and the interface never assumes prior investing knowledge.

---

## Scope

This project is well-suited for a team of **4–6 programmers** over one semester:

- **1) Not too simple**: The app requires a real-time (or near-real-time) data integration layer (stock price API), user authentication, persistent portfolio, transaction history, a dashboard with charting, learning modules, and a leaderboard.
- **2) Ambitious**: Though, We are not building a real brokerage. There are no real financial transactions, regulatory concerns, or complex order types. We can rely on a free-tier stock data API (e.g., Alpaca, or Yahoo Finance) and focus engineering effort on the application layer.
- **Clear milestones**: The project maps to iterative development — auth → portfolio → market data → learning modules → making it easy to scope for sprint-based delivery.
